# 碳足迹追踪平台部署指南

## 服务器信息
- IP: 111.231.141.121
- 系统: CentOS
- 后端端口: 8888
- 前端端口: 80

## 本地构建步骤

### 1. 构建后端
```bash
cd backend
mvn clean package -DskipTests
```

### 2. 构建前端
```bash
cd ..
cd frontend
npm run build
```

## 首次部署（服务器已配置）

### 1. 上传文件到服务器
```bash
cd ..
scp backend/target/carbon-footprint-tracker-1.0.0.jar root@111.231.141.121:/opt/carbonfootprint/backend/
scp -r dist/* root@111.231.141.121:/opt/carbonfootprint/frontend/
```

### 2. 重启后端服务
```bash
# SSH连接到服务器
ssh root@111.231.141.121

# 停止并删除旧容器
docker stop carbonfootprint
docker rm carbonfootprint

# 重新构建镜像
cd /opt/carbonfootprint/backend
docker build -t carbonfootprint-backend .

# 启动新容器
docker run -d --name carbonfootprint --network host --add-host=host.docker.internal:host-gateway -e SPRING_DATASOURCE_URL="jdbc:mysql://localhost:3306/carbonfootprint?useSSL=false&serverTimezone=UTC" -e SPRING_DATASOURCE_USERNAME=root -e SPRING_DATASOURCE_PASSWORD=123456 -e SPRING_REDIS_HOST=localhost carbonfootprint-backend

# 查看日志确认启动成功
docker logs carbonfootprint --tail 20
```

### 3. 前端自动生效
Nginx会自动加载新的前端文件，无需重启。

## 常用管理命令

### 查看服务状态
```bash
# 查看Docker容器
docker ps

# 查看后端日志
docker logs carbonfootprint --tail 50

# 查看所有服务状态
systemctl status nginx mariadb redis
```

### 重启服务
```bash
# 重启后端
docker restart carbonfootprint

# 重启Nginx
systemctl restart nginx

# 重启数据库
systemctl restart mariadb

# 重启Redis
systemctl restart redis
```

### 数据库管理
```bash
# 登录MySQL
mysql -u root -p123456

# 备份数据库
mysqldump -u root -p123456 carbonfootprint > backup.sql

# 恢复数据库
mysql -u root -p123456 carbonfootprint < backup.sql
```

## 故障排查

### 后端无法启动
```bash
# 查看详细日志
docker logs carbonfootprint

# 查看容器状态
docker ps -a

# 进入容器调试
docker exec -it carbonfootprint bash
```

### 数据库连接失败
```bash
# 检查数据库状态
systemctl status mariadb

# 测试数据库连接
mysql -u root -p123456 -e "SELECT 1;"

# 检查数据库字符集
mysql -u root -p123456 -e "SHOW VARIABLES LIKE 'character_set%';"
```

### 前端无法访问
```bash
# 检查Nginx状态
systemctl status nginx

# 查看Nginx日志
tail -f /var/log/nginx/error.log

# 测试Nginx配置
nginx -t
```
