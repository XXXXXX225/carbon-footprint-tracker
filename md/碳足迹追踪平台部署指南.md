1. # 碳足迹追踪平台部署指南

   ## 服务器信息
   - IP: 111.231.141.121
   - 系统: CentOS
   - 后端端口: 8888
   - 前端端口: 80

   ## 服务器初始配置

   ### 1. 系统更新
   ```bash
   yum update -y
   ```

   ### 2. 安装Docker
   ```bash
   yum install -y yum-utils
   yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
   yum install -y docker-ce docker-ce-cli containerd.io
   systemctl start docker
   systemctl enable docker
   ```

   ### 3. 安装MariaDB（MySQL）
   ```bash
   yum install -y mariadb-server mariadb
   systemctl start mariadb
   systemctl enable mariadb
   
   # 设置root密码
   mysql_secure_installation
   # 按提示操作，设置密码为123456
   
   # 创建数据库并设置字符集
   mysql -u root -p123456 -e "CREATE DATABASE IF NOT EXISTS carbonfootprint CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
   ```

   ### 4. 安装Redis
   ```bash
   yum install -y redis
   systemctl start redis
   systemctl enable redis
   ```

   ### 5. 安装Nginx
   ```bash
   yum install -y nginx
   systemctl start nginx
   systemctl enable nginx
   ```

   ### 6. 创建部署目录
   ```bash
   mkdir -p /opt/carbonfootprint/{backend,frontend}
   ```

   ### 7. 配置Nginx
   ```bash
   cat > /etc/nginx/conf.d/carbonfootprint.conf << 'EOF'
   server {
       listen 80;
       server_name 111.231.141.121;
   
       location / {
           root /opt/carbonfootprint/frontend;
           try_files $uri $uri/ /index.html;
       }
   
       location /api {
           proxy_pass http://localhost:8888;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
       }
   }
   EOF
   
   nginx -t
   systemctl restart nginx
   ```

   ### 8. 配置Dockerfile
   ```bash
   cat > /opt/carbonfootprint/backend/Dockerfile << 'EOF'
   FROM openjdk:17-jdk-slim
   WORKDIR /app
   COPY carbon-footprint-tracker-1.0.0.jar app.jar
   EXPOSE 8080
   ENTRYPOINT ["java", "-jar", "app.jar"]
   EOF
   ```

   ## 本地构建步骤

   ### 1. 构建后端
   ```bash
   cd backend
   mvn clean package -DskipTests
   ```

   ### 2. 构建前端
   ```bash
   cd ..
   npm run build
   ```

   ## 首次部署（服务器已配置）

   ### 1. 上传文件到服务器
   ```bash
   scp backend/target/carbon-footprint-tracker-1.0.0.jar root@111.231.141.121:/opt/carbonfootprint/backend/
   scp -r dist/* root@111.231.141.121:/opt/carbonfootprint/frontend/
   ```

   ### 2. 重启后端服务
   ```bash
   # SSH连接到服务器
   ssh root@111.231.141.121
   
   # 停止并删除旧容器
   docker stop carbonfootprint
   docker rm carbonfootprint
   
   # 重新构建镜像
   cd /opt/carbonfootprint/backend
   docker build -t carbonfootprint-backend .
   
   # 启动新容器
   docker run -d --name carbonfootprint --network host --add-host=host.docker.internal:host-gateway -e SPRING_DATASOURCE_URL="jdbc:mysql://localhost:3306/carbonfootprint?useSSL=false&serverTimezone=UTC" -e SPRING_DATASOURCE_USERNAME=root -e SPRING_DATASOURCE_PASSWORD=123456 -e SPRING_REDIS_HOST=localhost carbonfootprint-backend
   
   # 查看日志确认启动成功
   docker logs carbonfootprint --tail 20
   ```

   ### 3. 前端自动生效
   Nginx会自动加载新的前端文件，无需重启。

   ## 故障排查

   ```bash

   # 查看容器状态
   ```


   ```bash

   systemctl status nginx
   
   # 查看Nginx日志
   tail -f /var/log/nginx/error.log

   ```
